# 🛒 বাজার দর (BazarDor)

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক দাম ট্র্যাক করার ওয়েবসাইট।

🔗 Live: (https://bazar-dor-kohl-nine.vercel.app)

## Technologies
Next.js (App Router), TypeScript, Tailwind CSS, DaisyUI, BetterAuth, MongoDB, react-hot-toast

## Features
- পণ্যের আজকের দাম ও দাম বাড়া-কমার ▲/▼ badge
- লাইভ প্রাইস টিকার (marquee)
- ক্যাটাগরি অনুযায়ী পণ্য ও দাম অনুযায়ী Sorting
- প্রতিটি পণ্যের Dynamic Details Page (Protected Route)
- BetterAuth: Email/Password, Google ও GitHub লগইন
- My Profile ও নাম আপডেট
- Skeleton loading, Toast notification ও Responsive design

## Run locally
npm install
npm run dev
